Selected Projects

LLM-based Food Delivery User Click Simulator

Recommender Systems · Large Language Models · User Simulation · Behavior Modeling

This project investigates whether large language models can simulate user click behavior in food delivery recommendation scenarios. It compares traditional user simulators such as KuaiSim, vanilla LLM-based simulators, and LLM simulators enhanced with collaborative filtering signals.

  • Designed both single-click and multi-click user simulation tasks.
  • Constructed user profiles, short-term memory, merchant history, and candidate-level collaborative signals.
  • Evaluated simulation performance using Hit Rate, Accuracy, Precision, Recall, and F1.
